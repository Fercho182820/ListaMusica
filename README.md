Versión de Java
Desarrollado y probado con OpenJDK 25 en IntelliJ IDEA.
Funciona con Java 17 o superior; no usa ninguna característica nueva del lenguaje.

Abrir Main.java y al ejecutar se muestra un menú con 13 opciones; se elige escribiendo el número. 
La duración de las canciones se escribe en segundos (por ejemplo 180, no 3:00).

Abrir PruebasLista.java cada prueba muestra estado inicial, operación, resultado esperado y resultado obtenido, 
y comprueba que los enlaces de la lista sigan correctos. Al final imprime cuántas pasaron.

src/Cancion.java	          Datos de la canción (id, título, artista, duración) y su validación
src/Nodo.java	              Nodo con la canción y las referencias ant y sig
src/ListaReproduccion.java	La lista circular: inicio, fin, actual, cantidad y todas las operaciones
src/Main.java             	Menú de consola
src/PruebasLista.java	      Pruebas de funcionamiento
